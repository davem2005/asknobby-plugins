# askNobby plugins

This repository holds the public askNobby plugin. The application server is not in this repository.

The plugin folder is [asknobby](./asknobby). It contains the manifest, the skills, and the address of the remote server at https://www.asknobby.com/api/mcp.

The skills are get-started, find-work, manage-search, manage-applications, post-a-role, manage-roles, and manage-organisation. A company email can look for work or hire. The connection keeps the first capacity it is used for.
